# Analysis-of-Runtime-and-Memory-of-Data-Structures

1. What was the problem you were solving in the projects for this course?

In Project One, the task was to analyze and compare the runtime and memory efficiency of three data structures: Vector, Hash Table, and Binary Search Tree, for handling course data. Project Two involved creating a program that loads course data, sorts it alphanumerically, and retrieves detailed course information.

2. How did you approach the problem? Consider why data structures are important to understand.

I approached the problem by evaluating the requirements of each task and determining the most appropriate data structure. Data structures are important because they directly impact the efficiency of data storage, retrieval, and manipulation, which are key factors to consider in software performance and scalability.

3. How did you overcome any roadblocks you encountered while going through the activities or project?

For Project One, understanding the advantages and disadvantages of each data structure helped me in making my recommendation. In Project Two, challenges were addressed through thorough testing and iterative development of the code.

4. How has your work on this project expanded your approach to designing software and developing programs?

These projects emphasized the importance of aligning data structures with problem requirements. By considering runtime and memory constraints, I have been able to improve my ability to design programs that are both efficient and adaptable to varying sizes of data.

5. How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

Now I prioritize modularity by using classes and functions to encapsulate logic. Including clear and concise documentation and variable names is also essential in making my programs easier to maintain, scale, and adapt for future use.
